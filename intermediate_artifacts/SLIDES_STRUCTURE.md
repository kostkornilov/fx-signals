## 2. Проблематика

(если ты составляешь презентацию, перепиши эти предложения) Пользователи не имеют много времени чтобы следить за курсами валют. Нужно подсказывать пользователям выгодные моменты для перевода денег

## 3. Постановка задачи

Выбрать момент для отправки пуша, в который пользователь может перевести валюту по наиболее выгодному курсу. Выгодность курса в моменте определяется в сравнении с его динамикой в будущем

## 4. Выбранный подход

Решение об отправке пуша в момент времени T принимается на основе:
1. данных о динамике курса в прошлом
2. прогноза вероятности наступления некоторого события в будущем

При этом, пользователю сообщается только некоторый "сигнал" к переводу, видный на прошлых данных, который может его заинтересовать.

## 5. Откуда берется выгода

Выгода для пользователя достигается тем, что:
1. с помощью коммуникации мы приводим его на страницу переводов в нужный момент
2. помогаем следить за курсом, сообщая полезную информацию

При этом, мы сообщаем пользователю лишь часть известной нам информации - принимаем решение о коммуникации на основе прогноза, но пользователю его не говорим

## 6. Схема решения

1. Пул из быстрых и медленных аналитических сигналов, которые можно сообщить пользователю
2. Для каждого индикатора - ML-модель, которая предсказывает, будет ли текущий курс выгодным для некоторого окна в будущем
3. Мета-алгоритм, который собирает предсказания моделей для каждого из индикаторов, и принимает решение об отправке пуша

## 7. Что есть сейчас

MVP:
- 4 простейших индикатора
- аналитические правила вместо ML-моделей
- пуш отправляется, если хотя бы одно из правил сработало

## 8. Что в планах

1. Расширить пул индикаторов
2. Реализовать универсальные бэктесты
3. Использовать ML для предсказания "выгодности" курса в моменте
4. Использовать для предсказаний данные о других валютных парах, которые обновляются с большей гранулярностью
5. Детально проработать пользовательский опыт - тексты пушей, дизайн страницы переводов, возможность влияния на частоту пушей про курс валют
6. При устаревании пуша показывать статистику по другому индикатору
