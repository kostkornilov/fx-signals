# Контракт внешних временных рядов

Национальные банки и MOEX подключаются через один point-in-time CSV. Обязательные поля:

| поле | смысл |
|---|---|
| `event_date` | момент/дата наблюдаемого рынка |
| `available_at` | первый момент, когда значение могло быть использовано моделью |
| `source` | стабильный идентификатор источника (`nbt`, `cbu_uz`, `nbkr`, `cba`, `nbk_kz`, `moex`) |
| `series_id` | уникальный инструмент, например `nbt_usd_tjs` или `moex_cnyrub_close` |
| `value` | нормализованное числовое значение |

Опционально рекомендуется хранить `nominal`, `frequency`, `volume`, `fetched_at`, URL и SHA256
сырого ответа. Пары должны иметь одно явно задокументированное направление. Для кросса
`RUB/LOCAL = RUB/USD / LOCAL/USD` используется `fx_signal.external.triangulate_cross`.

Строка отклоняется, если `available_at < event_date`, имеются дубликаты point-in-time ключа или
разные `series_id` схлопываются в одинаковое имя признака. При присоединении используется только
последнее значение с `available_at <= decision_at`; заполнение из будущего запрещено.

Группа признаков `F` автоматически создаёт для каждого ряда доходности 1/5, процентиль за 90
наблюдений, волатильность за 20 наблюдений и число дней с последней публикации.
